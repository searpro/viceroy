# Moved to Notion

`docs/status.md` is no longer the source of truth. Project status now lives
in Notion:

- **Current State** — the point-in-time summary this file used to be.
- **Progress Tracker** (database) — one row per shipped PR/milestone/bugfix/
  decision, kept current by the `log-progress` skill.
- **Phases & Milestones**, and its per-milestone detail child pages — the
  full PR-by-PR narrative this file used to carry.

See [`docs/notion.md`](notion.md) for the links.

This file is kept only so a stale link or an old habit doesn't 404 or land on
an empty diff. Don't add content here — it won't be read.
